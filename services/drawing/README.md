### ตำแหน่งขั้วไฟของ BH-01 = ค่าอ้างอิงของ Appsale

`termPos: null` วางขั้วไฟที่ **152°** (BH-01) และกลางแนวแกนที่ 152°/332° (BH-01C) — **ตัวเลขนี้ Appsale เลือกเอง
ไม่ได้อยู่ในแคตตาล็อก** และรหัสสินค้าไม่มีท่อนบอกตำแหน่ง ⇒ แบบที่ส่งลูกค้าต้องมีข้อความกำกับว่าตำแหน่งขั้วไฟเป็นรูปอ้างอิง

### รูเจาะของ BH

ตัวสร้างตัดรูผ่านแถบจริงพร้อมตำแหน่ง `{x, y, d}` ครบแบบต้นฉบับ (ด่าน port มีเคสสังเคราะห์: แตะขอบ · คร่อมรอยผ่า ·
สองรูแตะกัน · บน BH-01C) แต่หน้าคำนวณราคารู้แค่ "กี่รู × ขนาดเท่าไหร่" ไม่รู้ตำแหน่ง ⇒ spec จากผลอ่านรหัส **ไม่มีรูเสมอ**
และ **ห้ามเรียงตำแหน่งรูเอง** (PM เคาะเฟส 0) — รหัสที่มีรู = วาดได้ (แบบไม่มีรู) แต่ส่งลูกค้าไม่ได้
