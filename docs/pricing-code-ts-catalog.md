## คำตอบของเจ้าของ 2026-09-29 (ทั้งหมด "ตามที่แนะนำ")

1. **หัว NTC/PTC ตามแคตตาล็อก** — `N2` `N10` `P2` `P10` (ชนิดหัววัด + 2K/10K) ใช้ได้กับ TS_-04 · 06 · 11 เท่านั้น คิดเป็นตาราง K/J + กฎ
   "NTC / PTC บวกเพิ่มจาก Type K/J" · แกน < 5 mm = ยังไม่มีราคา (ชีตไม่มีอัตรา · แคตตาล็อก 5 mm ขึ้นไป) · `P1` ไม่อยู่ในตาราง → บอกเหตุผล ·
   `TSN-` ยังพิมพ์ได้ แต่ไม่อยู่ใน dropdown · รหัสจริง 401 รหัส (04: 85 · 06: 49 · 11: 267)
2. **วัสดุ T / AT** = แกนเปล่า (T → `6` · AT → `6A`) + กฎ "หุ้มเทปล่อน" เต็มความยาวแกน L1 · แกนที่ชีตไม่มีอัตรา (นอก 4/6) = ยังไม่มีราคา
3. **2 Element ของชีตที่ Excel ไม่มีราคา** (TS_-04 · 10 · 11 · 12 RTD · 14) = แถวค่าว่าง "ยังไม่มีราคา" · TS-06 / 08 / 18 เปิดกฎของชีต
4. **TS_-11 Spring P (None Spring)** = ไม่มีผลกับราคา
5. **TS_-11 สายไม่ระบุ = สแตนเลสถัก** ทั้ง Thermocouple และ RTD (ตามตัวอักษรของแคตตาล็อก · RTD ที่เป็นพีวีซีต้องเขียน P) — ปิดข้อค้างจาก 2026-09-25
6. **หัว B** — TS_-14 ~~ไม่บวก~~ **= กฎ "หัวกระโหลก Blacklite ใหญ่" ของชีต** (เจ้าของแก้ในฐานแล้วยืนยัน 2026-09-29 "บวกตามที่ผมแก้" · K/S/E/SS/SB = ยังไม่มีราคา · KB = กฎเดียวกัน) · TS_-18 ยึด Excel +500 ทุกแบบ
7. **F1–F5 ของ TS_-18** → แถว JIS 10K ของชีต: F1 และ F2 ใช้แถว `3/4" , 1/2"` · F3 = 1" · F4 = 1 1/2" · F5 = 2"
8. **หัก L / หักฉาก** = ช่องติ๊กนอกรหัส (TS-06 · 08 · 10 · 11 · TSP-12)
9. **หน้าตา** — ช่อง "รุ่น" ช่องเดียวรวม BH กับ TS แบ่งกลุ่ม · TS_-12 สองรายการ (Thermocouple / RTD ตามแคตตาล็อกสองหน้า) · ชื่อในรายการ =
   ชนิดเซนเซอร์บนหัวหน้าแคตตาล็อก + คำในภาพประกอบ (Thread · Spring · Cable · Head · Flange · Sleeve) เพราะแคตตาล็อก TS ไม่มีชื่อรุ่นแบบ BH

ทำตามแนวเดิม (ไม่ต้องถาม): ตัวเลือกที่แคตตาล็อกมีแต่ Excel ไม่มีราคา = ยังไม่มีราคา · Ground U ไม่มีราคาเพิ่ม · ขนาดแกน + A/B/I/S = แถว Excel ตรงตัว ·

## ทุกรหัสได้ช่องกรอก · อะไรไม่ตรงแค่แจ้งเตือน (เจ้าของ 2026-10-01 · mockup `pricing-one-form.html`)

> *"ผมอยากให้ใช้ หน้าตา ui เป็นมาตรฐานเดียวกัน อะไรไม่ตรงก็แค่แจ้งเตือน"* — เคาะ mockup ทั้ง 3 ข้อ (สีสามระดับ · เลิกการ์ด

- รหัสที่ `readTsForm` ไม่รับ → `readTsFormLoose` (ไวยากรณ์หลวม: ทุกช่องเว้นได้ · ค่านอกรายการ · `cm` · ท่อนหลังเลขรุ่น `hj` · ท้ายรหัสอะไรก็ได้)
  ค่าตามที่เขียนอยู่ใน `written` / `clUnit` / `cableNoDash` / `headJunk` / `tail` / `omit` ⇒ `buildTsCode` ได้รูปเดิม
- `issues` รายช่องมาจากสองที่: แคตตาล็อก (`off` ค่านอกรายการ · `missing` ช่องที่ต้องบอกแต่ไม่บอก) และ **ตัวอ่านรหัส** (`code.ts` `tsFormOf`:
  ช่องที่ทับท่อน `unknown` = `unread` · ค่าใน `cfg.askPrice` = `ask`) ⇒ ช่องบนจอบอกตรงกับที่ราคาอ่าน ไม่ใช่โชว์ M6 ปกติทั้งที่ราคาไม่ได้ใช้
- สีบนจอ: เหลือง = เตือน (คิดได้) · ส้ม = ต้องขอราคา · แดง = อ่านไม่ออกจนคิดไม่ได้ · `M5`/`1/4` ที่เขียนออกมา = ค่ามาตรฐาน ไม่เตือน (`TsSlot.stdCode`)
- ต้องขอราคา (ราคาตั้งหาไม่ได้เพราะค่านอกแคตตาล็อก): `engine.ts` คิดกฎบวกเพิ่มต่อ (`askBase`) · กฎ % รอราคาตั้ง · กฎที่คิดไม่ได้ขึ้น
  "ยังไม่รวม" แทนการเปลี่ยนผลเป็นไม่รับผลิต · สถานะยังเป็น `quoteOnRequest` · จอโชว์ "ราคาเท่าที่คิดได้ — ยังไม่รวมส่วนที่ต้องขอราคา"
- วัด 2026-10-01 (16,396 รหัส TS ที่รู้รุ่น): ตรงทุกตัวอักษร **13,921 (84.9%)** · ที่เหลือ 2,475 ได้ช่องแบบหลวมทั้งหมด (ไม่มีตัวที่ไม่ได้ช่อง) ·
