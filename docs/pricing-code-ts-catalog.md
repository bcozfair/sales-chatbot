1. **หัว NTC/PTC ตามแคตตาล็อก** — `N2` `N10` `P2` `P10` (ชนิดหัววัด + 2K/10K) ใช้ได้กับ TS_-04 · 06 · 11 เท่านั้น คิดเป็นตาราง K/J + กฎ
