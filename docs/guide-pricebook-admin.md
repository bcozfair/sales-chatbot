# คู่มือ: แก้ราคาสินค้าสั่งทำด้วยตัวเอง

สำหรับ **แอดมินที่ดูแลราคา** — ไม่ต้องรู้เรื่องโปรแกรม ไม่ต้องเรียกใครมารันคำสั่ง
ใช้เวลาอ่านประมาณ 5 นาที แล้วทำตามได้เลย

---

## สิ่งที่ทำได้จากหน้าจอนี้

เข้า **Admin Portal → เงื่อนไข & กฎ → สมุดราคา** มีสองทางให้แก้ราคา **เลือกทางไหนก็ได้ ผลเหมือนกัน**
(ตั้งแต่ 2026-09-23 หน้า "คำนวณราคา" — เดิมชื่อ "คิดราคาสินค้า" — คิดราคาอย่างเดียว ปุ่มแก้ราคาทั้งหมดย้ายมาอยู่หน้านี้ ·
แก้ราคาแล้วอยากลองคิด กดปุ่ม **คำนวณราคา** มุมบนขวาของหน้านี้ได้เลย)

| ทาง | ใช้เมื่อไหร่ |
| --- | --- |
| **แก้บนหน้าจอ** (กดแถวของชีตในตาราง "ชีตในสมุดราคา") | แก้ชีตเดียว หรือแก้ไม่กี่ช่อง — เร็วที่สุด ไม่ต้องเปิด Excel |
| **ดาวน์โหลดแม่แบบ → แก้ใน Excel → อัปกลับ** (สองปุ่มมุมบนขวา) | แก้ทีเดียวหลายรุ่น หรืออยากให้คนอื่นช่วยแก้แล้วส่งไฟล์กลับมา |

ใต้ปุ่มมีการ์ด **"สมุดราคาที่ระบบใช้อยู่"** ซึ่งตอบได้ตลอดว่าราคาที่ระบบคิดอยู่ตอนนี้
มาจากไฟล์ไหน ใครแก้ เมื่อไหร่ — และมีปุ่ม **ย้อนไปเล่มก่อนหน้า** อยู่ตรงนั้นด้วย

---

## ทางที่ 1 · แก้บนหน้าจอ

ตาราง **"ชีตในสมุดราคา"** มี **1 แถวต่อ 1 ชีตของไฟล์ราคา Excel** (ตั้งแต่ 2026-09-24) — ชีต `TS-01+TS-01-0`
มีสองตารางในหน้าเดียว ก็เป็นแถวเดียวบนจอเหมือนกัน

### ชีตที่มีป้าย "แบบ Excel" — หน้าตาเหมือนในไฟล์

กด **เปิดชีต** แล้วจะเห็นทุกตารางของชีตนั้นเรียงบนลงล่างแบบในไฟล์: หัว **"ราคาตั้ง Standard TS_-01"** →
ตาราง ชนิดเซนเซอร์ (TYPE) × ขนาดเกลียว (THREAD) → แถบสีส้ม **หมายเหตุ** ราคาสายส่วนที่ยาวเกิน 1 เมตร

- คลิกช่องแล้วพิมพ์ทับได้เลย (เหมือน Excel) · ช่องที่แก้แล้วยังไม่บันทึกเป็น **พื้นฟ้า**
- คอลัมน์ **"ชนิดสาย รุ่นเริ่มต้น"** ท้ายตาราง **มีผลกับราคา** — รหัสที่ไม่ได้บอกชนิดสาย (เช่น `TSJ-01(1/4")4.8+2M`)
  ระบบคิดค่าสายส่วนที่เกิน 1 เมตรจากสายในคอลัมน์นี้ตาม TYPE · เปลี่ยนได้จากช่องเลือก · เลือก "ไม่มี" = รหัสแบบนั้นคิดไม่ได้จนกว่าจะระบุเอง
- ตัวหนังสือแดงใต้คอลัมน์ (`*M8x1.25` = ใช้ราคาเดียวกับ M8x1.0) และคอลัมน์ **พื้นเหลือง** แบบที่ไฟล์ไฮไลต์ไว้
  **เป็นข้อความกำกับ ไม่มีผลกับราคา** — แก้ข้อความได้ในช่อง · **คลิกหัวคอลัมน์** เพื่อสลับพื้นเหลือง
- **ช่องว่าง = ไม่รับผลิตแบบนั้น / สายชนิดนั้นต้องขอราคา — ไม่ใช่ราคา 0** ถ้าตั้งใจให้ฟรีต้องพิมพ์ 0
- เพิ่ม/ลบแถวหรือคอลัมน์ทำจากจอนี้ไม่ได้ — ใช้ทางที่ 2 (แม่แบบ Excel)
- กด **ตรวจก่อนบันทึก** จะเห็นทุกช่องที่แก้ (เดิม → ใหม่) · เลขที่เปลี่ยนเกิน 3 เท่าจะขึ้นเหลืองถามว่าพิมพ์ผิดหรือเปล่า
- บันทึกทั้งชีตเป็นครั้งเดียว ⇒ ย้อนทีเดียวกลับครบทั้งชีต
- ราคาสายในแถบหมายเหตุลอกมาจากชีต `TS-21+22+25` ไว้ในแต่ละตาราง — แก้ที่ตาราง TS_-01 ไม่ไปเปลี่ยนของ TS_-01-0

ชีตที่ยังไม่มีป้าย (BH และ TS ชีตอื่น) ยังเปิดหน้าแก้ **ทีละรุ่น** แบบเดิมข้างล่าง — จะย้ายมาเป็นแบบ Excel ทีละชีต

### ชีตอื่น — หน้าแก้ทีละรุ่น

กด **แถวของชีต** (หรือปุ่ม **แก้ราคา** ท้ายแถว · ชีต BH มีสองรุ่นจึงมีปุ่มแยก **แก้ BH-01,02** / **แก้ BH-03**)
แล้วจะเข้าหน้าแก้ราคาของรุ่นนั้น

ตารางบอกสามอย่างต่อรุ่น: **ชื่อ** · **รหัสที่ใช้ราคาเดียวกัน** (เช่น `TSJ/TS-04` = TSJ-04 กับ TS-04
คิดจากตารางของ TSK-04) · **สินค้าที่ครอบ** = จำนวนสินค้าในฐานที่คิดราคาจากรุ่นนี้ ⇒ แก้รุ่นนี้แล้วกระทบกี่รายการ
ชื่อรุ่น `BH-01,02` เขียนแบบเดียวกับหน้าข้อมูลสินค้า — BH-01 กับ BH-02 ใช้ตารางราคาเดียวกัน

**สี่ส่วนบนหน้านั้น**

1. **ราคาตั้ง** — ตารางช่วงขนาด · พิมพ์ทับตัวเลขได้ทุกช่อง · ปุ่ม **+ เพิ่มช่วงขนาด** ท้ายตาราง ·
   **ปุ่มถังขยะ** ท้ายแถวเพื่อลบช่วง
   บรรทัดล่างสุดคอยบอกว่าช่วงต่อกันครบไหม — ถ้าขึ้นเหลืองว่า *"ขนาด 11 ถึง 15 ไม่มีช่วงไหนรับ"*
   แปลว่าลูกค้าสั่งขนาดนั้นมาแล้วระบบจะคิดราคาไม่ออก **ต้องเติมช่วงให้ครบก่อน**
2. **รุ่น C** (เฉพาะซีรีส์ BH) — ดูหัวข้อถัดไป
3. **สิ่งที่ต้องบวกเพิ่ม** — ของแถม/ค่าบริการ
   · **สวิตช์ซ้ายสุด** = พักกฎไว้โดยไม่ลบ (ย้อนได้ ประวัติยังอยู่)
   · **ปุ่มดินสอ** = เปลี่ยนชื่อ / เงื่อนไข / วิธีคิด
   · **ปุ่มถังขยะ** = ลบทิ้ง · **+ เพิ่มกฎใหม่** = ตั้งกฎที่ไฟล์ราคาไม่เคยมี
   กฎที่เพิ่มเองจะติดป้าย **"เพิ่มเอง"** ไว้ เพื่อให้รู้ว่าไม่ได้มาจากไฟล์ราคา
4. **หมายเหตุ / ข้อจำกัด** กับ **ค่าที่ระบบคิดให้เอง** — เปิด/ปิดได้ แต่แก้ข้อความไม่ได้
   (เป็นด่านกันเสนอของที่ผลิตไม่ได้ กับสูตรที่พังแล้วทั้งรุ่นคิดราคาไม่ออก)

แก้เสร็จกด **ตรวจก่อนบันทึก** → จะเห็นตาราง **เดิม → ใหม่** ทุกช่องที่แตะ
แถวที่ติดป้าย **"โครง"** คือการเพิ่ม/ลบแถว ไม่ใช่แค่ขยับตัวเลข — ดูให้ดีก่อนกดบันทึก

> **ช่องราคาที่เว้นว่าง = ไม่รับผลิตขนาดนั้น ไม่ใช่ราคา 0**
> ถ้าตั้งใจจะแถมฟรีจริง ๆ ให้ **ใส่เลข 0** ไม่ใช่ลบเลขทิ้ง

### "รุ่น C" ของซีรีส์ BH คืออะไร

รหัสที่ลงท้ายเลขรุ่นด้วยตัว C (`BH-01C` · `BH-02C` · `BH-03C`) **ไม่ใช่รุ่นคนละรุ่น**
แต่คือรุ่นเดิมที่คิดเพิ่ม ⇒ ตั้งค่าที่เดียวในหน้าของรุ่นหลัก แล้วครอบทุกรหัสที่ลงท้ายด้วย C

| ช่อง | แปลว่า |
| --- | --- |
| สวิตช์ **เปิดใช้ รุ่น C** | ปิด = รหัสที่ลงท้ายด้วย C กลับไปคิดราคาเท่ารุ่นปกติทุกบาท |
| **บวกเพิ่มจากราคาปกติ %** | ใส่ **0** = ไม่บวกเพิ่ม (ต่างจากปิดสวิตช์ เพราะของแถมยังคิดราคาฝั่ง C อยู่) |
| **ราคาของแถมที่ต่างจากรุ่นปกติ** | กดถังขยะ = ของชิ้นนั้นกลับไปคิดเท่ารุ่นปกติ · กดชิป **+** ข้างล่าง = ดึงกลับเข้ามาตั้งราคาเอง |

**BH-03C จะมีป้ายเหลืองเตือนว่า "ยังไม่ได้ยืนยันกับฝ่ายขาย"** — เพราะไฟล์ราคาไม่เคยเขียนไว้ว่า
BH-03C คิดเพิ่มเท่าไหร่ ตัวเลขที่ใส่ไว้ให้ลอกรูปมาจาก BH-01C ⇒ **ถามฝ่ายขายก่อนใช้จริง**
ถ้าคำตอบคือไม่บวกเพิ่ม ให้ใส่ 0 ในช่อง % และลบรายการของแถมที่คิดเท่ารุ่นปกติออก

## ทางที่ 2 · ผ่านไฟล์ Excel (แก้ทีเดียวหลายรุ่น) — 4 ขั้น

### 1. กด "ดาวน์โหลดแม่แบบราคา"

ได้ไฟล์ชื่อประมาณ `แม่แบบราคา-2026-09-22.xlsx` ลงในโฟลเดอร์ดาวน์โหลด
ข้างในเป็นราคาทั้งหมดที่ระบบใช้อยู่ **ณ วินาทีที่กด**

### 2. แก้ตัวเลขใน Excel

แก้ได้ตามปกติ — พิมพ์ทับเลขเดิมได้เลย

> **ช่องที่เว้นว่าง = ไม่รับผลิตขนาดนั้น ไม่ใช่ราคา 0**
> ถ้าลบเลขออกจากช่องไหน ระบบจะเข้าใจว่า "รุ่นนี้ขนาดนี้ไม่รับทำแล้ว" แล้วรหัสที่ตรงกับช่องนั้น
> จะคิดราคาไม่ได้อีกเลย · ถ้าต้องการให้ราคาเป็นศูนย์จริง ๆ ให้พิมพ์ `0` ลงไป

**สิ่งที่ห้ามทำในไฟล์**

- ห้ามลบหรือเปลี่ยนชื่อหัวคอลัมน์ (ระบบใช้หัวคอลัมน์หาว่าแถวไหนคืออะไร)
- ห้ามลบชีตทิ้ง
- ห้ามพิมพ์คำลงในช่องราคา เช่น "สอบถาม" หรือ "-" — ช่องราคารับได้แค่ **ตัวเลข** หรือ **เว้นว่าง**

ทำผิดข้อไหน ระบบจะบอกตอนอัปกลับ พร้อมบอกว่าชีตไหนแถวไหน — **ยังไม่มีอะไรเสียหาย**

**ชีต "ตัวเลือกท้ายรหัส"** คือรุ่น C ที่อธิบายไว้ข้างบน เขียนเป็นแถวละรุ่น
ช่อง *"ราคาของแถมที่ต่างจากรุ่นหลัก"* ใช้รูปแบบ `รหัสกฎ=ราคา; รหัสกฎ=ราคา`
(เช่น `conn_pl2=320; nut=170`) — กฎที่ไม่มีชื่ออยู่ในช่องนี้ **คิดเท่ารุ่นหลัก**
ลบทั้งแถวทิ้ง = รุ่นนั้นไม่มีตัวเลือกท้ายรหัสอีกต่อไป

### 3. กด "อัปโหลดราคาใหม่" แล้วเลือกไฟล์

ระบบจะอ่านไฟล์แล้วขึ้นหน้า **"ตรวจก่อนบันทึก"** ให้ดูก่อน ซึ่งบอกว่า

- ราคากี่ช่องจะเปลี่ยน · เพิ่มใหม่กี่ช่อง · **หายไปกี่ช่อง** · เท่าเดิมกี่ช่อง
- ตารางรายช่อง: รุ่นอะไร ช่องไหน เดิมเท่าไหร่ ใหม่เท่าไหร่ ต่างกันเท่าไหร่

> **ขั้นนี้ยังไม่บันทึกอะไรทั้งสิ้น** ปิดไปเฉย ๆ ราคาก็ยังเป็นของเดิม

ถ้าเห็นป้ายแดง **"หายไป"** ให้หยุดดูก่อนว่าตั้งใจหรือเปล่า — มันแปลว่าช่องนั้นถูกเว้นว่างในไฟล์

### 4. เลือกรุ่นที่จะบันทึก แล้วกดปุ่มขวา

ด้านบนของหน้าตรวจมีชิปของทุกรุ่นที่ไฟล์นี้แตะ ติ๊กไว้ครบทุกรุ่นให้ตั้งแต่แรก

> **รุ่นที่ไม่ติ๊ก = คงราคาเดิมไว้ ไม่ได้ถูกลบ และไม่ได้หายจากสมุดราคา**
> ใช้ตอนที่แก้มาหลายรุ่นแต่อยากปล่อยของบางรุ่นไว้ก่อน

ปุ่มขวาจะเขียนว่า **"บันทึก N รุ่นที่เลือก"** — ตัวเลขบนปุ่มคือจำนวนรุ่นที่จะถูกเขียนจริง
กดแล้วมีผลกับการคิดราคา **ทันที**

## ถ้าอัปผิดไฟล์ไปแล้ว

กด **"ย้อนไปเล่มก่อนหน้า"** บนการ์ด "สมุดราคาที่ระบบใช้อยู่"

- ปุ่มนี้ย้อนไปเล่ม **ก่อนหน้าหนึ่งครั้ง** · บนการ์ดแสดงให้ย้อนได้ **3 เล่มล่าสุด**
- ระบบเก็บทุกการบันทึกไว้ในฐานข้อมูลตลอดไป (ตั้งแต่ 2026-09-23) เล่มที่กำลังใช้อยู่ตอนนี้ก็อยู่ในนั้น
  ⇒ **ย้อนผิดก็ย้อนกลับมาได้อีก** · เล่มเก่ากว่า 3 เล่มยังอยู่ ให้ฝ่ายโปรแกรมช่วยย้อนให้
- ราคาอยู่ในฐานข้อมูลแล้ว ⇒ **อัปเดตระบบ (deploy) ไม่ทำให้ราคาที่แก้ไว้หายอีก** และถูกสำรองทุกคืนพร้อมข้อมูลอื่น

## คำถามที่ถามบ่อย

**ถาม: อัปไฟล์แล้วราคาที่ลูกค้าเคยได้จะเปลี่ยนย้อนหลังไหม**
ไม่ — ใบเสนอราคาที่ออกไปแล้วเก็บราคาไว้ในใบของมันเอง การแก้สมุดราคามีผลกับ**ใบที่ออกหลังจากนี้**

**ถาม: ระหว่างที่ผมกำลังตรวจอยู่ มีคนอื่นอัปไฟล์เข้ามาด้วย จะทับกันไหม**
ไม่ — ระบบจะปฏิเสธการบันทึกของคุณ พร้อมบอกให้อัปไฟล์ใหม่อีกครั้งเพื่อดูส่วนต่างที่ตรงกับเล่มล่าสุด
ถึงสองคนจะกดบันทึกพร้อมกันเป๊ะ ระบบก็ยอมให้ผ่านได้คนเดียว
⚠️ ระบบนับ **ทั้งเล่ม** ไม่ใช่รายรุ่น — ถ้าคนอื่นบันทึกรุ่นไหนก็ตามระหว่างที่คุณเปิดหน้าค้างไว้
คุณจะต้องเปิดหน้าใหม่ก่อนบันทึก แม้จะแก้คนละรุ่นกันก็ตาม

**ถาม: ทำไมบางรุ่นไม่โผล่ในไฟล์**
ไฟล์แม่แบบมีเฉพาะรุ่นที่ระบบมีตารางราคาแล้ว รุ่นที่ยังไม่ได้ลอกตารางเข้ามาต้องให้ฝ่ายโปรแกรมทำก่อน

**ถาม: แก้ไฟล์เก่าที่ดาวน์โหลดไว้เมื่อสัปดาห์ที่แล้วได้ไหม**
ได้ แต่ส่วนต่างที่เห็นจะเทียบกับเล่ม**ปัจจุบัน** ⇒ ถ้ามีคนแก้ราคาไประหว่างนั้น การบันทึกจะทับของเขาด้วย
ปลอดภัยกว่าคือ **ดาวน์โหลดใหม่ทุกครั้งก่อนแก้**

**ถาม: แก้บนหน้าจอกับแก้ผ่าน Excel ต่างกันไหม**
ผลเหมือนกันทุกประการ — ทั้งสองทางเขียนลงสมุดราคาเล่มเดียวกัน และเก็บเล่มเก่าให้ย้อนเหมือนกัน
ต่างกันแค่ความสะดวก: หน้าจอเร็วกว่าเมื่อแก้ไม่กี่ช่อง · Excel สะดวกกว่าเมื่อแก้ทีเดียวหลายรุ่น

**ถาม: ใครกดปุ่มพวกนี้ได้บ้าง**
คนที่เปิดหน้า **สมุดราคา** ได้ (ช่อง **สิทธิ์ตามบทบาท → สมุดราคา** · ค่าเริ่มต้น admin คนเดียว)
สิทธิ์นี้ **แยกจากหน้าคำนวณราคา** ตั้งแต่ 2026-09-23 ⇒ เปิดหน้าคิดราคาให้เซลส์ใช้ได้โดยเขาแก้ราคาไม่ได้
คนที่มีแค่สิทธิ์คิดราคาจะเห็นรหัสย่อยที่อ่านไม่ออกเป็นแถบแดงเหมือนเดิม แต่ไม่มีปุ่ม ＋ เพิ่ม
