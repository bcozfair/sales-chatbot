## 3. ระบบทำอะไร (หลังเจ้าของเคาะ 2026-09-24)

| ช่องในรหัส | ระบบทำอะไร | อยู่ที่ไหน |
| --- | --- | --- |
| ชนิด Sensor | K/J แถว `TSK/TSJ` · T → `TST` · P → `TSP` · PA → `TSPA` · Z → `TSZ` | แถวของตารางราคาตั้ง |
| เกลียว / Hold Size ในวงเล็บ | คอลัมน์ของตาราง · `M8x1.25`/`M10x1.5` ใช้ราคาเดียวกับ M8/M10 | คอลัมน์ของตารางราคาตั้ง |
| เกลียว **None** (ไม่มีวงเล็บ) | **TS_-01 = 1/4” · TS_-01-0 = M5** · บรรทัดราคาเขียนว่า "= ค่ามาตรฐานของรุ่น — รหัสไม่ได้ระบุ" | `axisDefaults.thread` ของรุ่น (แมป 19/20) · หน้าชีตติดป้าย "มาตรฐาน" ใต้หัวคอลัมน์ |
| ขนาดแกน 4.8 / 6 (TS_-01) | ไม่มีผลกับราคาตั้ง (ราคาอยู่ในคอลัมน์เกลียว) · **ใช้เลือกอัตราของความยาวแกน** — ตัวอ่านรหัสจำเป็นแกน `D` เมื่อรุ่นมีกฎที่แยกราคาตาม `D` (2026-09-25) | กฎ `len_l1` · แถว `6` ในตารางรหัสย่อยยังอยู่แต่ไม่ถูกใช้แล้ว (ตัวอ่านเจอในกฎก่อน) |
| `X` ความยาวแกน (TS_-01) | **เกิน 5 mm คิด 100 mm ละ ปัดขึ้น: แกน 4.8 = 110 · แกน 6 = 120** (เจ้าของสั่ง 2026-09-25 — *"เริ่มคิดเงินเมื่อยาวเกิน std ของแต่ละรุ่น"* · *"ยึดราคาจาก excel"*) · x10 = +110 · x105 = +110 · x106 = +220 | กฎ `len_l1` (แมป 19 อ่าน `TS-06!C27`/`C31` — ชีต TS-01 ไม่มีคอลัมน์นี้) · `standard.L1 = 5` · แก้ได้ที่แถบ "ความยาวแกน" หน้าสมุดราคา |
| `+NM` ความยาวสาย | มาตรฐาน 1 M · ส่วนที่เกิน **นับเฉพาะเมตรเต็ม** (เจ้าของ 2026-09-25 · `+1.5M` ไม่คิด · `+2.5M` คิด 1 ม.) คิดตามชนิดสาย (สแตนเลสถัก 80 · ไฟเบอร์กลาส 95 · พีวีซี 100 · เทปล่อน 180 · **เทปล่อนหุ้มชีลด์ 160** บาท/ม.) · **ไม่มีค่าเปลี่ยนชนิดสายในเมตรแรก** | กฎ `cable_over_1m` — แก้ได้ที่หน้าสมุดราคา แถบราคาสายใต้ตาราง |
| ชนิดสาย **None** | **สแตนเลสถัก ทุก Sensor** (ไม่ใช่คอลัมน์ G ของชีตที่บอก TST = เทปล่อน · TSP = PVC) | `axisDefaultsBy.cable` ค่าเดียวกันทุกแถว — หน้าชีตยังแก้ราย TYPE ได้ |
| ชนิดสาย T/P/F/C/TS | อ่านจากตัวอักษรหลัง M (C/TS ของ TS_-01-0 เพิ่ม 2026-09-25) | **ตารางรหัสย่อย** (`scripts/pricebook/catalog-subcodes.json` → `seedCatalogSubcodes.ts`) |
| Ground `U` | Unground **ไม่มีราคาเพิ่ม** | ตารางรหัสย่อย `U` (effect `none`) |

**ทำไมตัวอักษรหลัง M อยู่ในตารางรหัสย่อย ไม่ใช่ในโค้ด** — แต่ละรุ่นมีไม่เท่ากัน และร้านต้องแก้เอง
ได้จากหน้าสมุดราคาโดยไม่รอ deploy · `readCable()` ตัดท้ายเป็นท่อนที่ตารางรู้จัก **ยาวสุดก่อน**
(`TSU` = `TS` + `U`) และ **ต้องอ่านได้ครบทุกตัวอักษรถึงจะใช้** — รุ่นที่ไม่มีแถว `TS` จะไม่แตก `TSU` เป็น
`T` + `SU` แล้วคิดเป็นเทปล่อน แต่ขึ้นแดงทั้งท่อน · ปุ่ม **＋ เพิ่ม** ข้างท่อนสีแดงใช้ได้จริงแล้ว

**ชนิดสายที่เพิ่มผ่านตารางรหัสย่อย ได้ช่องราคาบนหน้าสมุดราคาเอง** (2026-09-25 · เจ้าของ: *"ต้องสามารถแก้ไขผ่าน ui ได้"*)
— ช่องราคาสายเดิมมาจากคีย์ที่มีราคาอยู่แล้วเท่านั้น ⇒ C/TS ซึ่งไม่มีในชีต Excel ไม่มีช่องให้กรอก · ตอนนี้ค่าแกนที่แถว
`setAxis` ตั้งให้รุ่นนั้นได้ ขึ้นเป็นช่องว่างเสมอ (`knownRateKeys` ใน `modelEditor.ts`) · route ของหน้าแก้ต้องส่งเล่มที่รวม
รหัสย่อยจากฐานแล้ว (`editorBook`) แต่ **บันทึกด้วยเล่มเดิม** ไม่งั้นแถวรหัสย่อยถูกคัดลอกลงสมุดราคา

⚠️ **รหัสที่บอกสายแล้วอ่านไม่ออก ห้ามได้สายตั้งต้น** (`ProductConfig.unread`) — ก่อนแก้ `TSK-01(M6)4.8+2MT`
เคยได้ 240 (สแตนเลสถัก) พร้อมคำว่า "รหัสไม่ได้ระบุ" ทั้งที่ต้องเป็น 340 (เทปล่อน) · ไม่เคยขึ้นใช้จริง

**ส่วนที่อ่านไม่ออก = เตือน แล้วคิดเฉพาะส่วนที่คำนวณได้** (เจ้าของสั่ง 2026-09-25: *"รหัสที่อ่านไม่ออกให้ขึ้นเตือนไว้
แต่คำนวณเฉพาะส่วนที่คำนวณได้ไปก่อน"*) — สายที่อ่านไม่ออก ⇒ กฎค่าสายถูก **ข้าม** (ไม่ใช่เติมสายตั้งต้น)
เป็น `Violation` ระดับ `warn` ที่มี `partial: true` · ราคาที่ได้ = ราคาตั้ง + กฎที่คิดได้ เช่น `TSK-01-0(M6)+2MTSU` = **190**
(ยังไม่รวมค่าสายส่วนเกิน) · หน้าคำนวณราคาเปลี่ยนหัวเป็น **"ราคาเฉพาะส่วนที่คำนวณได้"** และมีกล่อง **"ราคานี้ยังไม่ครบ"**
ไล่ทุกอย่างที่ยังไม่รวม (กฎที่ข้าม + ท่อนสีแดงอย่าง `-S###`) · ส่วนที่ **คำนวณไม่ได้เลย** (ไม่รู้เกลียวเมื่อรุ่นไม่มีค่ามาตรฐาน
· ช่องว่างในตาราง) ยังไม่ได้ราคาเหมือนเดิม

**สายที่แคตตาล็อกมีแต่สมุดยังไม่มีราคา** (วันนี้เหลือ C) — สายไม่เกิน 1 M คิดได้ปกติ · เกิน 1 M
ขึ้น **"ยังไม่มีราคาในสมุดราคา"** (`Violation.noRate`) ไม่ใช่ "ไม่รับผลิต" — ช่องว่างในตารางราคาตั้งเท่านั้น
ที่แปลว่าไม่รับผลิต

**ยังไม่ได้ทำเป็นกฎ:** "Thermocouple Type T จะมีเฉพาะสายสแตนเลสถักและเทปล่อน" — รหัสจริงของ TST ทั้งสองรุ่น
ใช้ T หรือไม่ระบุทุกตัว (วัด 2026-09-24) และการเพิ่มกฎ (`constraints`) จะทำให้ชีตนี้เปิดแบบ Excel ไม่ได้
(`excelReady`) ⇒ ถ้าต้องบังคับ ต้องทำให้หน้าชีตรองรับกฎก่อน

### `-S###` = งานสั่งทำพิเศษ ไม่ใช่รหัสราคา

- 304 จาก 305 รหัส มี `internal_reference` เป็น `FCU…` (`CU` = สินค้าสั่งทำ — `docs/plan-local-products.md`)
- เลขนับต่อจากรหัสเดิม: S000 = แบบพิเศษแบบแรก · S001 = แบบที่สอง … (`TSK-01 4.8+1M` มี S000–S029)
- สิ่งที่ทำพิเศษอยู่ใน **`products.sales_description`** (274 / 309) เช่น "ไม่ใส่สปริง" · "เกลียวยาว 15mm." ·
  "น็อตตัวเมีย+หางปลาเข็ม" · "ตามแบบ"
